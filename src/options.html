使用提示与隐私

本地文件：拖入阅读器，或选择「打开 PDF」，支持一次导入多份文件。扫描件暂不支持文字翻译与全文搜索；有密码的文件每次重新打开都需输入密码。

Chrome / Edge 内置 PDF 阅读器无法直接提供选区。推荐用本阅读器；也可先 Ctrl+C，再使用扩展弹窗中的剪贴板翻译。

文章对话需要可用的自定义 AI 接口；仅发送问题、必要的历史和检索到的文章片段，不默认上传整份 PDF。AI 的回答与引用都需要核对原文，不能替代学术判断。

文档库、译文、笔记与对话保存在本机，可在文档库备份和恢复。插件版与应用版使用各自的数据目录，通过备份迁移。不含云同步、遥测或自动更新下载。

划词快速模式可能把选中文字发送给多个免费翻译服务。不希望发送给免费服务时，请选择「自定义 API」并关闭「快速译文 + AI 优化」。

API Key 不会回显或写入分发包。应用版使用系统加密保存凭据；插件版凭据受浏览器个人资料保护。文档备份为未加密 ZIP，含原文和对话，不包含 API 设置或密钥，请勿随意转发。
