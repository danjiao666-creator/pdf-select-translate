「自动」= 配了自定义 API 就优先用它，否则依次尝试 Google → Microsoft。 免费接口无需 Key，但在部分网络环境（例如中国大陆直连 Google）可能不可达； 此时建议配置 DeepSeek 等 OpenAI 兼容接口。

修改快捷键请打开 chrome://extensions/shortcuts（Edge 为 edge://extensions/shortcuts）。 在内置 PDF 阅读器里只有快捷键能触发翻译，右键菜单不会出现。

怎么用（推荐流程）

  1. 在网页上打开 PDF → 点扩展图标 →「用翻译阅读器打开本 PDF」。
  2. 在自带阅读器里直接用鼠标划选句子，松手即出译文；可开启「整句」自动补全句子边界。
  3. 本地文件：把 PDF 拖进阅读器窗口，或点「打开本地 PDF」。本地文件不受跨域限制，最稳。
  4. 也可以在任何普通网页上划词翻译（同一套引擎与设置）。

为什么需要自带阅读器？Chrome/Edge 内置的 PDF 阅读器由插件渲染，网页脚本拿不到选区、 也收不到鼠标事件，扩展只能靠快捷键 + 剪贴板间接工作。自带阅读器基于本地打包的 pdf.js， 文字层完全可访问，才能真正「选中即翻译」。
