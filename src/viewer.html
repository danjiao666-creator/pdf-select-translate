暂无文档

将 PDF 拖入窗口，或点击「导入 PDF」。打开过的文件会自动加入文档库。

文件不自动上传。翻译和对话时，相关文字才发送到你配置的服务。卸载、清除应用数据或浏览器数据会删除文档库，请定期备份。备份为未加密 ZIP，请妥善保管；密码 PDF 不保存密码。

全文翻译

  • 识别分栏与段落，按原页面位置排入译文；AI 翻译会参考标题、摘要和相邻段落。
  • 公式、细小图内标签、旋转文字和扫描页保留原文。无法安全排版的段落不强行覆盖或缩成小字，点击虚线区域查看完整译文。
  • 仅发送文字及必要的上下文，不上传 PDF 文件；使用付费 API 会产生用量费用。免费引擎不具备文档上下文能力，专业文献建议选择 AI。
  • 支持暂停、继续和失败重试；暂停后已发出的请求可能继续计费。旧版译文不会沿用到新的排版流程。
